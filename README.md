#### 三、 项目介绍

基于SpringBoot摄影器材租赁系统

包含前台用户模块、后台模块（管理员、供应商）三部分，具体功能如下：
1. 前台用户模块
基础功能模块：首页、摄影器材、社交论坛、摄影资讯、AI 智能对话
个人中心功能：修改密码、租赁订单、配送信息、收货信息、归还器材、我的发布、我的收藏
2. 后台管理员模块
全流程管理功能：
基础管理：系统首页、用户管理、供应商管理、设备分类管理
业务管理：摄影器材管理、租赁订单管理、配送 / 收货信息管理、归还器材管理
互动与系统管理：举报记录管理、论坛分类 / 社交论坛管理、系统管理
3. 后台供应商模块
器材租赁运营功能：系统首页、摄影器材管理、租赁订单管理、配送 / 收货信息管理、归还器材管理、个人中心
该系统聚焦摄影器材租赁场景，通过前台用户完成器材查询、租赁与个人事务管理，供应商负责器材与订单运营，管理员统筹平台资源与秩序，实现摄影器材从租赁预订到归还的全流程数字化，适配摄影爱好者的器材租赁需求。

#### 四、项目技术

是否前后端分离项目：是

后端： SpringBoot+Mybatis-Plus

前端：Vue + Vue Router + ELementUI + Axios

开发语言：Java

开发工具：IDEA，Eclipse,Myeclipse都可以。推荐IDEA

JDK版本：1.8

数据库: MySQL8.0版本以上

#### 六、安装教程

使用Navicat或者其它工具，在mysql中创建对应名称的数据库，并导入项目的sql文件；

进入src/main/resources修改application.yml里面的数据库配置
